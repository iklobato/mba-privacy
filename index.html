Política de Privacidade

Extensão: AutoJur · Teses vencedoras (IA Contestações). Última atualização: 4 de agosto de 2026.

Esta extensão é uma ferramenta de uso interno de um escritório de advocacia. Ela funciona apenas dentro do sistema AutoJur do escritório e tem duas partes: um painel que sugere teses jurídicas para o processo aberto na tela, e um assistente de perguntas e respostas sobre a base de processos do escritório.

Quem pode usar

Só quem está logado no AutoJur do escritório. A extensão confirma o login a cada uso. Sem uma sessão ativa no AutoJur, ela não mostra nada.

Quais dados a extensão usa

DadoPara quê
Cookie de sessão do AutoJur Confirmar que a pessoa está logada. O cookie é trocado por um código de acesso que vale 20 minutos. A senha do AutoJur nunca é lida nem guardada.
Nome da conta no AutoJur Saber de quem é cada conversa do assistente, para que ninguém veja a conversa de outra pessoa. O nome é lido pelo servidor, na própria página do AutoJur.
Número do processo (CNJ) e nome do cliente Lidos da página do processo que já está aberta, para buscar as teses daquele caso.
As perguntas escritas no assistente Responder à pergunta. As conversas ficam guardadas para a pessoa poder voltar nelas depois.
Dados de uso Saber se a ferramenta está sendo usada e se alguém está com uma versão antiga. Registramos qual tela foi aberta, qual botão foi usado, a versão do plugin instalada e um código aleatório que identifica o navegador (não a pessoa). O texto das perguntas não entra nesse registro.
Registro de acesso Por exigência de proteção de dados, guardamos quem acessou dados de processo, quando, por qual endereço e de qual IP.

Para onde os dados vão

Os dados vão para o servidor do próprio escritório, hospedado no Google Cloud, e para mais nenhum outro lugar, com uma exceção descrita abaixo.

A exceção: o assistente usa uma inteligência artificial do Google

Quando alguém faz uma pergunta no assistente, o texto da pergunta e os dados de processos usados para respondê-la são enviados ao Google (Vertex AI, modelo Gemini), que é quem gera a resposta. Hoje esse processamento acontece fora do Brasil, porque o modelo usado não é oferecido na região brasileira. O painel de teses não usa inteligência artificial e não envia nada ao Google.

Os dados guardados (a base de processos, as conversas e os registros) ficam em servidores no Brasil, na região de São Paulo.

Compartilhamento

Os dados não são vendidos, alugados nem usados para publicidade, avaliação de crédito ou qualquer finalidade fora do propósito da ferramenta. Fora do Google, citado acima, na condição de prestador de serviço que processa a pergunta, nada é compartilhado.

Por quanto tempo fica guardado

  • Registro de acesso e dados de uso: 180 dias, depois são apagados.
  • Conversas do assistente: ficam até a pessoa apagar. Cada um só vê e só apaga as próprias.
  • O código de acesso do plugin vale 20 minutos e não fica guardado no servidor.

O que fica guardado no seu navegador

Só duas coisas, no armazenamento local da extensão: o endereço do servidor do escritório e um código aleatório que identifica aquele navegador. Esse código é criado pela própria extensão, não vem de nenhum serviço de rastreamento e não é usado para seguir a pessoa em outros sites. A extensão não guarda histórico de navegação.

Quando o plugin é instalado ou removido

Na instalação e na remoção, a extensão avisa o servidor do escritório, enviando o código aleatório do navegador e a versão instalada. Serve para saber quantas instalações existem e quem ainda está com uma versão antiga. Nesse momento não há nome de pessoa nenhum.
