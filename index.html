Política de Privacidade

Extensão: AutoJur · Teses vencedoras (IA Contestações). Última atualização: 24 de julho de 2026.

Esta extensão é uma ferramenta de uso interno de um escritório de advocacia. Ela funciona apenas dentro do sistema AutoJur do escritório e serve para sugerir teses jurídicas ligadas ao processo aberto na tela.

Quais dados a extensão usa

  • Cookie de sessão do AutoJur: a extensão lê o cookie da sessão já logada no domínio do AutoJur do escritório para confirmar que o usuário está autenticado.
  • Número do processo (CNJ) e nome do cliente: lidos da página do processo que já está aberta no AutoJur, para buscar as teses relacionadas ao caso.

Como os dados são usados

Esses dados são enviados apenas ao servidor (backend) do próprio escritório para: (1) confirmar o login e gerar um token de acesso de curta duração, e (2) devolver as teses sugeridas para o processo. A tese que o advogado escolhe é gravada como uma Tarefa dentro do próprio AutoJur, após revisão do advogado. Nada é gravado automaticamente.

Compartilhamento

Os dados não são vendidos, alugados ou compartilhados com terceiros. Eles trafegam somente entre o navegador do usuário e o servidor do próprio escritório. A extensão não usa os dados para publicidade, avaliação de crédito ou qualquer finalidade fora do seu propósito único.

Armazenamento

A extensão guarda localmente apenas uma configuração: o endereço (URL) do servidor do escritório. Não guarda histórico de navegação nem dados pessoais no dispositivo.
